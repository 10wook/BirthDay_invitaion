# Asset 교체 가이드

이 폴더에 실제 미디어 파일을 추가하면 초대장 콘텐츠가 자동으로 반영됩니다.

## images/
- `hero/` — Hero 섹션 배경/프로필 이미지
- `story/` — 스토리 섹션 사진 (01.jpg, 02.jpg ...)
- `gallery/` — 갤러리 슬라이드 사진
- `timeline/` — 타임라인 연도별 사진 (2024.jpg ...)

## videos/
- `hero-bg.mp4` — Hero 배경 영상 (muted, loop)
- `memory.mp4` — 추억 영상

## music/
- `bgm.mp3` — 배경 음악

> config 파일(`src/config/content.ts`, `src/config/site.ts`)에서 경로와 텍스트를 수정할 수 있습니다.
