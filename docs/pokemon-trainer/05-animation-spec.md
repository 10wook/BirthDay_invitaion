# Animation Specification

| Element | Effect | Tool |
|---------|--------|------|
| Loading progress | width 0→100% | GSAP |
| Loading text | typewriter | GSAP |
| Hero | stagger fade up | GSAP |
| Badges | scale in + bounce | ScrollTrigger |
| EXP bar | scrub width | ScrollTrigger |
| Party cards | fade up stagger | ScrollTrigger |
| Buttons | tap scale | Framer |

Rules: transform + opacity only, no canvas/Three.js
