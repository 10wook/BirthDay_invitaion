# 컴포넌트 구조

## Decorations

| 컴포넌트 | 역할 |
|----------|------|
| `FloatingDecorations` | 페이지 전역 CSS/SVG 장식 (GPU 최소) |
| `Sparkle` | 반짝이 포인트 |

## UI

| 컴포넌트 | 모바일 스펙 |
|----------|-------------|
| `Button` | 둥근 pill, primary pink, min-h 48px |
| `SectionTitle` | Bagel Fat One, 24~28px |
| `ScrollIndicator` | bounce + "아래로" |
| `Modal` | 크림 배경, 핑크 border |

## Sections

| 섹션 | 모바일 레이아웃 |
|------|----------------|
| Hero | 100vh, 프로필 원형, 파스텔 그라데이션 |
| Story | 세로 스택, 4:5 이미지 |
| Gallery | Swiper, slidesPerView 1.15, 4:5 |
| Video | 9:16 또는 4:5, rounded-3xl |
| Timeline | 세로 카드, 좌우 slide |
| Countdown | 2×2 grid |
| Location | 세로, 지도 버튼 full-width |
| RSVP | 세로 2버튼 full-width |
| Closing | 텍스트 reveal + 하트 |
